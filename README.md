# KREDOS

Адаптивное PWA-приложение для составления заказов строительных материалов по объектам.

## Возможности

- русский, латышский и украинский языки;
- адрес объекта и название заказа;
- материалы, количество, единицы, цена и ссылка на товар DEPO;
- локальное сохранение заказа и каталога;
- экспорт CSV, печать/PDF и системная отправка;
- установка на компьютер, Android и iPhone как веб-приложение.

Для GitHub Pages нужно публиковать содержимое папки `dist`.
